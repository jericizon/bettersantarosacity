## Check 2 — /money stubs redirect + visible moved-link: FAIL

- **Redirect behavior: present.** `dist/money/index.html` is `<meta http-equiv="refresh" content="0; url=/finances">`; `dist/money/budget/index.html` → `url=/finances/budget`.
- **Visible moved-link: ABSENT.** The generated files contain only `<head>` — no `<body>`, no anchor, no `<title>`. The intended "This page has moved to /finances" link exists in source (`pages/money/index.vue:10-12`, `pages/money/budget.vue:10-12`) but `await navigateTo(..., { redirectCode: 301 })` short-circuits SSR, so the template never renders into the artifact.
- Impact: meta-refresh `0` still forwards all real browsers; failure mode hits users/crawlers with refresh disabled and produces an invalid, empty HTML document. Also no `/money` 301 entries in `dist/_redirects` (only `/* /404.html 404` fallback).
